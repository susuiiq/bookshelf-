A Java app for organizing your personal reading list by genre.

## Features

- Browse Fantasy, Romance, Sci-Fi, Mystery, and Non-Fiction shelves
- Add books with a title, author, rating, and optional review
- Rate books from 0 to 5 stars, including half-stars like 3.5
- View one shelf or your whole collection
- Ratings display like `***+` for 3.5 stars

## How to Run

```bash
javac VirtualBookshelf.java
java VirtualBookshelf
